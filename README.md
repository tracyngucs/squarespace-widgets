All widgets are mobile optimised

Widget has 4 tools:
1. vid-image carousel
2. youtube gallery
3. testimonies category listing
4. testimonies page combined for Items 2 and 3

Mainly, it has 2 tools (Item 1 and 4)
Items 2 and 3 are needed to get Item 4

How to use:
1. In edit mode, upload images and videos
2. Paste into widget builder in live mode
3. Grab embed code and paste as code block into target page in edit mode
4. Live page will populate widget correctly

How to restore previous session:
1. It saves according to browser history
2. If using on different device, copy embed code from last published
Click on load from existing embed code and paste

Once session is restored, amend accordingly and paste updated embed code as code block into target page
Live page will populate widget accordingly
